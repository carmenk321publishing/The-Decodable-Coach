# The Decodable Coach

Part of the **Atlantis Learning Archives**. A teacher pastes a draft decodable text, chooses a target UFLI Foundations lesson, and the site reports whether the draft **fits** that level, could be **refined**, or uses language that is **coming later** in the sequence.

## How it works
1. Choose the target lesson (Lessons 1-128).
2. Paste the draft and list any heart (irregular) words already taught.
3. Review: each word is labelled target, review, heart word, coming soon, coming later, or needs a manual check.
4. Refine: swap suggestions, a word bank for the level, and a text report to save.

## Important limits
- The checker uses a rule-based approximation of the UFLI scope and sequence (lesson map built from the public UFLI Foundations Toolbox). It is a first pass, not a replacement for professional review.
- It does not check spelling. Always verify against the official [UFLI Foundations Toolbox](https://ufli.education.ufl.edu/foundations/toolbox/).
- Heart-word introduction lessons are not hard-coded; confirm them in the UFLI Step 7 slides.
- Independently created to align with the UFLI Foundations scope and sequence; not reviewed, approved, or endorsed by UFLI or the University of Florida.
