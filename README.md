# The Decodable Coach

Part of the **Atlantis Learning Archives**. A teacher pastes a draft decodable text, chooses a target lesson from the UFLI Foundations sequence, and the site reports whether the draft **fits** that level, could be **refined**, or uses language that is **coming later** in the sequence.

> **Notice:** The Decodable Coach is inspired by the UFLI Foundations scope and sequence. It is **not officially aligned with, reviewed by, or endorsed by** UFLI or the University of Florida.

## How it works
1. Choose the target lesson (Lessons 1-128).
2. Paste the draft and list any heart (irregular) words already taught.
3. Review: each word is labelled target, review, heart word, coming soon, coming later, or needs a manual check.
4. Refine: swap suggestions, a word bank for the level, and a text report to save.

## Important limits
- The checker is a rule-based first pass built from a lesson map of the public UFLI Foundations Toolbox. It is not a replacement for professional review.
- It does not check spelling. Always verify against the official [UFLI Foundations Toolbox](https://ufli.education.ufl.edu/foundations/toolbox/).
- Heart-word introduction lessons are not hard-coded; confirm them in the UFLI Step 7 slides.
